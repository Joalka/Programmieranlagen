Dies ist ein StatsCalculator für Pokemon, 
im speziellen für mein selbstentworfenes Pokemon-PnP Regelset.
Er ist inspiriert von dem Calculator von Pokewiki, aber von Grund auf selbst entworfen und
personalisiert im Bezug auf das eigene Pokemon-PnP Regelset.

Wenn der Button "Load" gedrückt wird,
wird aus der Klasse StatCalc.Pkmn_Liste_Import der Datensatz der Artenspezifischen Stärken gezogen 
und die Berechnungen der eingegeben Daten ausgeführt. 

Anhand der Spielregeln wird gezeigt wie viele Fleiß-/Skillpunkte vergeben werden dürfen.
Die Button "Max/Min FP" sind nur für Bequemlichkeit und wenn noch keine IS vorhanden sind,
welche der/die Nutzer*in eingeben möchte kann auch mit "Random IS" zufällig generiert werden,
wobei es von -3 bis 3 7 verschiedene EInstellungen zum generieren gibt.

Da diese Daten leicht in andere Programme übertragen können werden sollen, 
werden sie unten links direkt im korrekten Format zum kopieren ausgegeben.
